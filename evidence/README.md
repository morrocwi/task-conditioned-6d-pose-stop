# Evidence discipline (glosa application)

This repository uses the five-question / E-A-D discipline from **glosa — Rigour Without Infrastructure** as reporting governance, not as evidence that the robotics hypothesis is true.

- **Q1** What was actually seen/run?
- **Q2** What does the record alone separate?
- **Q3** What did AI add?
- **Q4** What is assumed?
- **Q5** What independent evidence or objection was run?

The public CI is an **I4 mechanical/original-record** check. It does not constitute I5 independent human replication. The current public status is therefore **K1 public provisional**, explicitly not peer reviewed or physically validated.

The mechanically validated record is `claim_card.json`. `validate_claim_card.py` checks required disclosure fields; it does not certify their semantic truth.
